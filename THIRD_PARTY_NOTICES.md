# Third-party assets

## FANUC M-10iD/12 robot model

- Source: [RoboDK robot library](https://robodk.com/robot/Fanuc/M-10iD-12)
- Download: <https://cdn.robodk.com/downloads-library/library-robots/Fanuc-M-10iD-12.robot>
- Local asset: `assets/Fanuc-M-10iD-12.robot`
- The same robot geometry is embedded in `Celula_Polimento_FANUC.rdk` and visible in the showcase images.

The robot model is a third-party asset, not an original model authored for this project. RoboDK and FANUC names and marks belong to their respective owners. This repository is an independent portfolio project.

## RoboDK software and API

RoboDK is required to open and execute the station. The application and its licence are not supplied by this repository. The Python builder imports the separately installed RoboDK API; it does not bundle its source or the postprocessor implementation.

## Project-created material

The Python builder, workpiece mesh, conceptual tool and fixture geometry, cell layout, motion sequence, documentation and screenshots were created for this project. The screenshots show the actual RoboDK station, including the third-party robot model credited above.
